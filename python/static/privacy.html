隐私政策

版本：V1.1 · 生效日期：2026年9月18日

一、我们收集的信息

  • 账号信息：昵称、大学年级、研究方向、密码的加盐哈希。
  • 项目信息：项目名称、简介、方向、组内氛围、成员标签、成员和申请记录。
  • 协作内容：话题聊天、引用和撤回状态、共享文件、项目公告与通知。
  • 安全信息：登录时间、登录失败、限流事件、举报、处罚、申诉和审计日志。

平台不要求填写身份证号、手机号、学号、家庭住址、银行卡等与协作功能无关的敏感信息。

二、信息用途

  • 完成注册、登录、项目发布、成员审批、聊天、文件共享和消息提醒。
  • 判断项目权限、处理举报和申诉、执行禁言或封禁，并记录管理员操作。
  • 发现限流、越权、文件异常和会话异常等安全事件。
  • 当项目负责人明确授权 Project Agent 分析时，把授权范围内的项目讨论和资料元数据发送给部署方配置的模型服务商，用于整理信息、发现问题和提供研究建议。Agent 不读取私人聊天、其他项目或系统凭据。

三、存储与保留期限

数据保存在部署方控制的服务器、SQLite 数据库和备份目录中。账号存续期间保留账号和协作数据；账号注销或内容删除后，活动数据停止展示，备份副本会随备份轮换清理。部署方应根据实际运营地区和法律要求设置最终保留期限。

四、谁可以查看

  • 项目成员可以查看所属项目的聊天、成员和文件；非成员不能查看。
  • 私密项目的详情、成员和加入密码仅对项目成员、申请者和管理员开放。
  • 管理员在处理举报、申诉、安全事件或执行管理操作时，可以查看必要的数据。
  • 平台不会把用户数据出售给第三方。

五、日志与安全

  • 安全日志记录账号、操作、时间、结果和脱敏后的上下文。
  • 平台不把密码、密码哈希、会话令牌、CSRF 令牌或 AI API Key 写入审计日志。
  • 平台使用密码哈希、会话 Cookie、CSRF 校验、对象级权限校验、文件类型校验、限流和上传大小限制等措施降低风险。

六、文件与备份

上传文件存放在平台数据库中，只有项目成员和管理员可按权限访问。部署方可使用数据库备份脚本生成 SQLite 一致性备份，备份轮换策略默认保留至少 7 份。备份目录不得包含 .env 或生产密钥。

七、第三方服务

平台可以配置兼容 OpenAI 接口的第三方大语言模型，也可以使用本地模型。Agent 是否启用、使用哪个服务商由部署方决定。发送给模型的内容仅限负责人主动授权分析所需的项目文本，不发送密码、密码哈希、会话令牌、Cookie 或系统配置。

八、你的权利

你可以查看和修改自己的昵称、年级和方向；可以删除自己发送的消息、上传的文件或负责的项目。你可以通过站内举报或管理入口联系运营方，申请查询、更正、删除个人信息或注销账号。

九、注销与删除

  • 注销后账号不能继续登录，账号关联内容按法律法规、安全需要和备份轮换策略处理。
  • 删除项目会移除项目下的聊天、文件和申请记录；管理员操作可能保留脱敏审计日志。
  • 备份中的数据不会立即覆盖删除操作，会在后续备份轮换中清理。

十、政策更新

平台更新本政策时，会通过站内公告说明版本和生效日期。继续使用更新后的服务，视为你已知晓更新内容。

十一、联系方式

如对本政策或个人信息处理有疑问，请通过站内举报或管理入口联系运营方。
